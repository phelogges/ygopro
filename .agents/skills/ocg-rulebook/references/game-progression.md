# 游戏的进行

## 游戏准备

1. 双方洗切各自的卡组，之后适当地洗切对手的卡组（切牌）
2. 猜拳，胜者选择先攻/后攻
3. 多局比赛：第一局猜拳，之后由败者选择先攻/后攻（平局则猜拳）
4. 初始手卡5张，初始基本分8000
5. 先攻玩家的回合开始前双方不得使用任何卡

## 优先权

### "发动卡"的优先权
- 各阶段/步骤等特定时点，回合玩家拥有发动最初卡的权利
- 持有此优先权时可以发动诱发即时效果、速攻魔法、陷阱卡
- 可选的诱发效果或表侧魔法·陷阱的效果，即使不持有优先权也能发动
- 必发效果满足条件时，即使不持有优先权也能发动
- 优先权转移给对方：玩家放弃优先权或发动了卡/效果的场合
- 回合进入下个阶段需要双方都放弃优先权

### "回合前进"的优先权
- 与"发动卡"的优先权不同
- 由回合玩家持有，宣言进入下个阶段/步骤

## 回合流程

一个回合由6个阶段构成，依次进行。每个阶段/步骤需要在双方放弃优先权且效果处理全部完成后才能结束。

### 1. 抽卡阶段
- 回合玩家最开始从卡组抽1张（通常抽卡）
- **先攻第1回合不能通常抽卡**
- 抽卡结束前不能进行任何卡的发动·处理（除替代抽卡的效果和"抽卡前"发动·处理的效果）
- 卡组无卡可抽时决斗败北

### 2. 准备阶段
- 需要发动·适用的效果从回合玩家开始
- 时机任意的卡由玩家决定处理顺序

### 3. 主要阶段1
- 可进行：怪兽的召唤·盖放、条件特殊召唤、反转召唤、表示形式变更、魔法·陷阱的发动/盖放/效果发动、怪兽起动效果的发动、P怪兽作为魔法卡的发动
- 结束时可选择进入战斗阶段或结束阶段
- 先攻第1回合不能进行战斗阶段

### 4. 战斗阶段
分为4个步骤，先攻第1回合不能进行。

**开始步骤**：
- 宣言进入战斗阶段
- 进行"战斗阶段开始时"效果的发动和处理

**战斗步骤**：
- 1只怪兽1回合1次攻击宣言
- 攻击顺序：选择攻击怪兽→对方场上有怪兽时选择攻击对象→对方场上无怪兽时直接攻击
- 攻击宣言后，"攻击宣言时"效果从回合玩家开始发动·处理

**战斗的卷回**：
- 自己的怪兽攻击宣言后，战斗步骤中对方怪兽数量发生变化时发生
- 最终数量未增减的场合也当作数量变化
- 己方怪兽数量增减不引发卷回
- 卷回发生时可重新选择攻击对象或停止攻击
- 重新选择时不当"攻击宣言时"
- 因效果不能直接攻击的场合也发生卷回
- 怪兽召唤·特殊召唤时发动的效果处理完毕后发生卷回
- 卷回只在战斗步骤发生

**伤害步骤**：
- 基本上只能发动必发效果，例外可发动的卡：
  - 反击陷阱
  - 使卡·效果发动无效的效果
  - 增减怪兽攻守的效果（仅限伤害计算前）
  - 反转时发动的怪兽效果
  - 自身特殊召唤成功时发动的效果
  - 自身被破坏·除外·加入手卡时发动的效果等

伤害步骤分为5段：

1. **伤害步骤开始时**："不进行伤害计算"等效果
2. **伤害计算前**：里侧怪兽变成表侧守备表示（反转效果不发动）；增减攻守的效果（"突进""收缩""欧尼斯特"等）
3. **伤害计算时**：
   - 依照攻守数值进行伤害计算，扣除基本分
   - 攻击表示对攻击表示：比较攻击力，差值给予低攻方伤害，低攻怪兽破坏（同攻则双破坏）
   - 攻击表示对守备表示：攻击力>守备力时守备怪兽破坏；守备力>攻击力时差值给予攻击方伤害
   - 直接攻击：给予攻击力数值的战斗伤害
   - 确定被战斗破坏的怪兽：永续效果从此时不再适用，直到送去墓地为止不能成为效果对象
   - 攻击力0之间的战斗：双方不受伤害，怪兽不破坏
   - "可以作为代替破坏"的效果在此时适用
4. **伤害计算后**："伤害计算后"效果、"给与战斗伤害时"效果、反转时发动的效果
5. **伤害步骤结束时**：战斗破坏的怪兽送去墓地；"被战斗破坏送去墓地时"等效果发动

**结束步骤**：
- 战斗阶段结束
- "战斗阶段结束时"效果等处理
- 结束后进入主要阶段2

### 5. 主要阶段2
- 仅在进行了战斗阶段后进行
- 与主要阶段1相同
- 1回合1次的行动在M1进行过的不能再进行
- 不能再进入战斗阶段

### 6. 结束阶段
- 结束阶段开始时和进行中需要处理的卡和效果
- 双方放弃优先权后，存在必发效果或必须处理的效果的场合从回合玩家开始处理
- 结束阶段发动的诱发效果发动被无效后不能再度发动
- **手卡调整**：全部处理结束后，回合玩家手卡7张以上时需丢弃到6张为止（不当"因效果丢弃"）
- "直到回合结束时"的效果：直到手卡调整结束为止适用
- 结束后进入对方回合

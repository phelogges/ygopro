# 大会规则

## 基本规则

- 采用"新大师规则（2020年4月1日修订版）"
- 1场比赛 = 先获得2场决斗胜利 / 最多3场决斗

## 禁止·限制·准限制卡

公式大会必须遵守限制规章。

| 类别 | 卡组·副卡组·EX卡组合计最多使用 |
|------|-------------------------------|
| 禁止卡 | 0张（不能使用） |
| 限制卡 | 1张 |
| 准限制卡 | 2张 |

## 外语版卡

- 商店决斗和公式大会以外，原则上可与日语版一起使用
- 背面设计不同时，有使用卡套遮挡的义务
- 不能使用对应日语版不存在的其他语言的卡
- 使用海外发售的卡时，需准备确认日语版文本的材料（日语版卡或记载日语版效果用纸等）
- 使用电子设备表示卡片情报的场合，仅能使用公式网站"OCG卡片数据库"
- 需对效果作出适当说明

## 卡组初期化

- 玩家有义务把上一场比赛换入的卡恢复到比赛开始前的状态
- 不承认各轮（各场比赛）第1场决斗前在卡组·EX卡组和副卡组之间进行卡的替换
- 决斗开始前需向对手说明EX卡组和副卡组的张数

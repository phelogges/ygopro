# OCG 规则书

游戏王OCG完整规则参考。根据用户问题加载对应的参考文件，避免一次性加载全部内容。

## 使用方式

1. 根据用户问题确定涉及的领域
2. 打开对应的参考文件（通常1-2个足够，跨领域问题时加载多个）
3. 如果问题涉及"连锁+效果"组合，同时加载 effects.md 和 game-progression.md
4. 如果问题涉及卡片类型+召唤方式，加载 cards.md
5. 如果问题涉及场地布局+区域规则，加载 field.md

## 核心原则

- 基本规则与卡片文本矛盾时，以卡片文本为准
- 善用例句解释复杂规则
- 注意区分"卡的发动"和"效果的发动"
- 涉及"场合"与"时"的区别时，务必说明能否发动
- 涉及cost时，说明cost必须在发动时支付且发动被无效也无法取回

# 决斗录制目标：魔术礼帽①效果

## 用户原话

> 录制决斗剧本，目标是验证 81210420 的1效果

## Agent 整理目标

1. 由一方在对手战斗阶段发动「魔术礼帽」（81210420），记录发动提示及合法选择。
2. 从发动方主要怪兽区选一只怪兽，再从卡组选两张魔法或陷阱卡；核对双方各自可见的展示和盖放信息，不把一方未知的卡片身份补进该方快照。
3. 核对原怪兽变成里侧守备，以及三张里侧怪兽在主要怪兽区被洗切后的观测。洗切后的具体位置是随机结果，不能按本次录制的格子序号断言未来每次相同。
4. 战斗阶段结束时，核对由效果从卡组特殊召唤的两张卡被破坏、原怪兽仍在场的可见结果。

## 录制安排与限制

- 建议 Host 使用 `deck/test/4.ydk`：起手有 81210420 与通常怪兽，卡组里有两张可供选择的魔法或陷阱卡；Guest 可选能进入战斗阶段的卡组。
- Host 先攻时盖放「魔术礼帽」并召唤或盖放一只主要怪兽；Guest 回合进入战斗阶段后由 Host 发动。双方完成效果及战斗阶段后，再手动结束对局。
- 本次标记为随机场景，因为效果调用 `Duel.ShuffleSetCard`。录制时随机场景 v2 尚未支持这类洗切消息；随后已补充解析与回放验证，具体证据见同目录 `README.md`。

# 决斗录制目标：河马狂欢节①特殊召唤三只衍生物

## 用户原话

> 录制决斗剧本，目标是验证 18027138 的1效果，特殊召唤3只衍生物

## Agent 整理目标

1. 在人工双客户端对局中发动「河马狂欢节」（18027138）的①效果；记录发动方收到的合法候选、实际选择，以及双方可观察的发动和连锁处理过程。
2. 确认效果结算后，发动方场上新增恰好三只「河马衍生物」，分别占据合法怪兽区格子；核对双方各自可见的特殊召唤事件与后置场面。具体格子由实际录制决定，不预设。
3. 区分这次由效果产生的三只衍生物与其他怪兽；若效果无效、可用区域不足或实际召唤数量不同，按事实标记目标未完全达成。
4. 仅验证本次特殊召唤三只衍生物的协议与场面结果。额外卡组特殊召唤限制、不能解放及攻击对象限制不作为本场景的必需目标，除非对局实际触发并有可见证据。

## 录制安排

- 使用人工准备的双方卡组；人工建房、选卡组并完成决斗。
- 使用严格确定性模式：单局 1v1，启用「不洗牌」，起手五张、LP 8000、每回合抽一张、无时间限制。
- 对局结束后审核双端日志、场景编译、无头回放和目标断言，待用户审核后才收录正式回归集。

# 决斗录制目标：「天岩户」②结束阶段返回手牌

## 用户原话

> 录制决斗剧本，目标验证 32181268 的2效果结束阶段回到手牌

## Agent 整理目标

1. 在人工双客户端对局中召唤或反转「天岩户」（32181268），让它留在怪兽区直到该回合的结束阶段；记录双方可见的召唤、阶段变化、②效果发动与连锁处理。
2. 核对②效果在召唤／反转的同一回合结束阶段发动，而不是在主要阶段提前回手；若存在发动提示，记录其合法候选与实际处理。若该卡提前离场或效果未发动，按实际证据标记目标未完成。
3. 结算后核对「天岩户」从怪兽区返回其原持有者手牌：持有者客户端能看到该卡 ID，另一端只能按自身可见的移动事件、怪兽区减少及对手手牌数量变化断言，不揭示隐藏手牌身份。
4. 若效果被无效或因其他效果改变去向，不把“可回放”当作“已回手”。具体玩家和格子按实际录制决定。

## 录制安排

- 使用人工准备的双方卡组；人工建房、选卡组并完成决斗。
- 使用严格确定性模式：单局 1v1，启用「不洗牌」，起手五张、LP 8000、每回合抽一张、无时间限制。
- 对局结束后审核双端日志、编译报告、无头回放及目标断言，待用户审核后才收录正式回归集。

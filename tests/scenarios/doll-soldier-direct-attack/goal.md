# 决斗录制目标：「人偶兵卒」①直接攻击

## 用户原话

> 录制决斗剧本，验证 89839552 的1效果，可以直接攻击对手玩家

## Agent 整理目标

1. 让「人偶兵卒」（89839552，原本攻击力 800）在本方怪兽区以表侧攻击表示进入战斗阶段；对手场上尽量保留至少一只可攻击怪兽，以区分“凭①效果直接攻击”和“对手空场时通常可直接攻击”。记录双方场上状态，确认没有其他允许直接攻击或改变战斗伤害的效果。
2. 由同一只「人偶兵卒」选择直接攻击对手玩家。核对本方合法攻击候选／攻击选择、双方各自可见的 `attack_declared` 事件：攻击者是「人偶兵卒」所在怪兽区格子，目标为空／玩家，而不是对手怪兽格子。
3. 核对伤害步骤内双方观察到的伤害事件和后置生命值：若攻击力仍为 800，且没有其他伤害修正，应由对手承受 800 点战斗伤害；本方 LP 不变。对攻击宣言到伤害步骤结束之间的伤害事件写次数与数值断言，避免只靠终局 LP 判断。
4. ①为允许直接攻击的持续效果，不要求出现 `effect_activated`。这张卡的②效果可能在造成战斗伤害后提示是否发动；它不在本次测试目标内，可由人工选择不发动，但必须把实际选择和后续结果写入剧本。

## 录制安排

- 人工双客户端建房、选卡组并决斗至终局；测试目标与具体动作以实际录制事实核查。
- 严格确定性模式：单局 1v1，必须启用“不洗牌”，起手五张、LP 8000、每回合抽一张、无时间限制。
- 双端日志、实际 YDK、编译和单场回放先留在忽略目录；用户审核后才收入正式场景集合。

# 决斗录制目标：「妖精传姬-辉夜」②将怪兽返回手牌

## 用户原话

> 录制决斗剧本，目标验证 86937530 的2效果，弹怪兽卡回手牌

## Agent 整理目标

1. 在人工双客户端对局中发动「妖精传姬-辉夜」（86937530）的②效果，以对方场上一只表侧怪兽为对象；记录双方各自可见的发动、目标选择和连锁处理。
2. 核对对手是否获得“从自身卡组或额外卡组送同名卡去墓地使效果无效”的选择；本目标要求实际结算走未送同名卡的分支。若对手送出同名卡并使效果无效，本局不宣称完成返回手牌的目标。
3. 成功结算后，核对「妖精传姬-辉夜」及对象怪兽分别从场上离开并回到各自持有者手牌；双方仅断言本视角可见的卡片身份、移动事件和手牌数量，不用另一端日志揭示隐藏手牌身份。若对象是额外卡组怪兽而不会回手牌，应按实际结果标记目标未完全达成。
4. 记录实际怪兽、场上格子和手牌变化，不预设具体卡片或位置。仅有动作回放成功不足以证明“回手牌”，需要可见事件与后置状态支持。

## 录制安排

- 使用人工准备的双方卡组；人工建房、选卡组并完成决斗。
- 使用严格确定性模式：单局 1v1，启用「不洗牌」，起手五张、LP 8000、每回合抽一张、无时间限制。
- 对局结束后审核双端日志、编译报告、无头回放及目标断言，待用户审核后才收录正式回归集。

## 录制后审查补充

实际对局还发生了第二次②效果：另一方从卡组送出目标同名卡，使连锁项失效。它不替代第一次成功弹回的主目标；候选场景额外验证这条确定性的无效分支，并明确断言第二次没有怪兽回手牌。

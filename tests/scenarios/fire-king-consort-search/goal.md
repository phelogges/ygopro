# 决斗录制目标：「炎王妃 火神不死鸟」①检索怪兽

## 用户原话

> 录制决斗剧本，目标验证 44455560 的1效果，检索卡组中的怪兽

## Agent 整理目标

1. 在人工双客户端决斗中，让「炎王妃 火神不死鸟」（44455560）召唤或特殊召唤，并实际发动①效果。记录发动提示、效果身份及双方可见的连锁过程。
2. 核对效果处理时从自己手牌或表侧场上破坏另一只炎属性怪兽，再从卡组将一只符合条件的炎属性兽族、兽战士族或鸟兽族怪兽加入手牌。具体被破坏和检索的卡按实际录制确定；不预设卡片 ID。
3. 双端分别核对卡组到手牌的移动、公开展示（若客户端确实收到）、本方手牌中的检索结果及对方隐藏手牌边界。若随后选择改变此卡等级，也按实际提示和快照记录，但不把它当作检索成功的必要条件。
4. 录制结束后，对检索、破坏和后置状态各自标明“已验证／部分验证／未验证”，补充可执行断言并只回放本场景。若卡牌或规则交互带来额外决策，按双端实际日志整理，不预先假定分支。

## 录制安排

- 人工准备并选择双方卡组、建房、决斗至终局；开发 Agent 不预设具体牌组和检索对象。
- 使用严格确定性模式：单局 1v1，必须启用「不洗牌」，起手五张、LP 8000、每回合抽一张、无时间限制。
- 双端日志、实际提交的 YDK 和自动编译回放留在忽略目录；经审核确认后才收录 `tests/scenarios/`。

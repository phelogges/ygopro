# 决斗录制目标：天子的指轮②效果

## 用户原话

> 录制决斗剧本，验证 40678060 的2效果必发效果，不入连锁无效发动的魔法卡的效果

## Agent 整理目标

1. 一方让「天子的指轮」（40678060）以装备卡状态表侧存在，对方发动可观察结果的魔法卡效果。
2. 核对「天子的指轮」②在符合条件时自动适用：该方无需选择是否发动②，且②不形成新的连锁项。
3. 核对原魔法卡效果在处理时被无效，记录双方各自可见的消息顺序和后置场面。区分“魔法卡效果无效”与“魔法卡发动无效”；卡面写的是前者。
4. 如对局中还演示同回合第二次对方魔法卡效果，额外核对②每回合仅无效一次；若没有演示，不据此声称覆盖次数限制。
5. 双端录制、编译候选与回放断言分别核查；协议没有直接暴露的因果关系应注明证据边界。

## 录制安排

- 使用人工准备的双方卡组；录制前不读取或修改卡组文件。
- 本局默认严格确定性模式：单局 1v1，启用「不洗牌」，起手五张、LP 8000、每回合抽一张、无时间限制。
- 人工完成目标效果演示后结束对局，随后检查双端日志、编译与回放结果。

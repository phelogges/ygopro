## 双视角证据

1. Host 通常召唤「火山鼠」，先让其装备「团结之力」（56747793），再装备「天子的指轮」。Guest 发动「旋风」（05318639），选择 Host 场上的「团结之力」为对象（Guest #450–#452）。
2. 双端均观察到「旋风」的 `effect_activated`、`chain_link_added`、`chain_link_solving`。从该发动到连锁结束，各端已接受的事件中只有一个 `chain_link_added`，且没有「天子的指轮」的 `effect_activated`。录制的 Host 在这段处理过程中没有手动接受②的决策提示；空响应窗口仅被客户端自动放弃。
3. 双端在「旋风」的连锁 1 处理时均收到 `MSG_CHAIN_DISABLED`（Host #502、Guest #480），随后 `chain_link_solved` 和 `chain_ended`。双方快照显示被「旋风」选择的「团结之力」仍表侧留在 Host 魔法陷阱区，「天子的指轮」也仍在场；「旋风」进入 Guest 墓地。
4. YAML 的双端有序事件断言要求该连锁被无效，区间计数断言要求「旋风」发动到连锁结束间恰好一个连锁项、零个「天子的指轮」效果发动事件。严格决策流也会在额外需要人工选择②的提示出现时失败。

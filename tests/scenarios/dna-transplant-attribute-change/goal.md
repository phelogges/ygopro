# 决斗录制目标：「DNA移植手术」改变表侧怪兽属性

## 用户原话

> 录制决斗剧本，目标验证 56769674 的效果，改变场上表侧表示怪兽的属性

## Agent 整理目标

1. 使用「DNA移植手术」（56769674）发动时宣言一种属性，并让场上至少一只表侧表示怪兽的原属性与宣言属性不同。优先让双方场上各有一只这样的怪兽，以验证其适用于**场上所有**表侧怪兽；具体宣言与怪兽按实际录制事实判定。
2. 记录陷阱发动、属性宣言的语义动作和双端可见事件；核对该卡在魔法陷阱区持续表侧存在。分别比较同一只表侧怪兽在效果适用前后的属性，要求变为所宣言属性，双方快照与增量事件不应互相矛盾。
3. 若录制期间另有表侧怪兽进场，检查它在此卡仍表侧存在时的属性；若此卡离场，检查属性是否恢复。这两种扩展情况只按实际发生的过程记录，不作为本次必须完成的目标。
4. 不以卡片原本属性或效果文本代替客户端可见证据；若录制前后缺乏可比较的快照或消息，应如实标为部分验证。对只通过场面状态可确认的持续效果，不强求每只怪兽都有独立的 `effect_activated` 事件。

## 录制安排

- 人工双客户端建房、选卡组并决斗至终局；具体卡组、怪兽、宣言属性以实际提交和操作为准。
- 严格确定性模式：单局 1v1，必须勾选“不洗牌”，起手五张、LP 8000、每回合抽一张、无时间限制。
- 双端原始日志、实际 YDK、编译草稿和单场验证先保留在忽略目录；用户审核后才收入正式测试集。

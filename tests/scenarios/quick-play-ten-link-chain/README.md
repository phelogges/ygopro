用户原话及录制前整理见 [goal.md](goal.md)。本场要求至少两张速攻魔法卡进入**同一条连锁**，核对双方的发动选择、连锁加入顺序和逆序处理。实际录制形成了十项连锁，因而将十项全部写入断言。

- 有效录制：`out/duel-recordings/001aa1ecdc614b5bb3caeb792bac0989/`，状态 `validated`，编译报告 `compiled`，无阻断错误。
- 先前中止的录制 `54ef93fdf77c4cfc87857e01fad93c90` 不用于本场景。
- 本目录的 `host.ydk`、`guest.ydk` 和 `scenario.yaml` 来自有效录制的编译草稿；后者增加了目标断言。

## 断言与结果

- 双端各有 41 条有序事件断言：十次 `effect_activated` 与 `chain_link_added`、十项逆序的 `chain_link_solving` 与 `chain_link_solved`、最后 `chain_ended`。`chain_index` 区分同名卡和同一连锁中的各项。
- 双端各有一条区间计数断言：从连锁 1 发动到首次连锁结束，`chain_link_added` 恰好出现十次，防止有序子序列匹配遗漏额外连锁项。
- 编译器保留了双端合法提示、实际动作和终局可见场面断言。双方各支付两次「宇宙旋风」的 1000 LP；连锁结束后双方 LP 均为 7200，魔陷区清空。最终由 Host 投降，Guest 胜；胜负方式不属于测试目标。
- 加断言后的独立双客户端 HTTP v3 无头回放为 `passed`：`out/agent-e2e-runs/1791653440-80727/scenario-report.json`。原始编译草稿回放报告：`out/agent-e2e-runs/1791653240-77199/scenario-report.json`。
- 收录后全量运行七场景 HTTP v3 回放，`passed: 7`、`failed: 0`、`unsupported: 0`：`out/agent-e2e-runs/batch-1791653689-86101/batch-report.json`。本场为第 4 项。

## 审核结论与边界

目标中的“至少两张速攻魔法卡属于同一条连锁并逆序处理”已由双端录制和回放断言验证；实际覆盖十项。效果对象的规则因果没有从最终场面倒推，也没有验证真实 LLM 的选择、GUI 演出或 Windows。用户已审核目标解释与断言范围，本场景收入正式回归集。

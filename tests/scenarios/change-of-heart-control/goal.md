# 决斗录制目标：「心变」①取得对方怪兽控制权

## 用户原话

> 录制决斗剧本，目标验证 04031928 的1效果，获得对手场上一只怪兽的控制权

## Agent 整理目标

1. 在人工双客户端对局中，发动「心变」（04031928）的①效果，选择对方场上一只怪兽作为对象；记录发动候选、选中对象及双方各自可见的连锁处理。
2. 效果成功结算后，核对被选中的怪兽从原控制者怪兽区移至发动方怪兽区，卡片身份与新控制者在双方各自视角下可辨；分别核对双方收到的跨控制者移动事件和后置场面。规则上的原持有者（`owner`）与当前控制者（`controller`）分开；本次 Agent 快照若未收到有效 `QUERY_OWNER`，不把原持有者字段列为机器验证目标。具体怪兽与格子由实际录制决定，不预设。
3. 若对局经过结束阶段且该怪兽仍能返回，进一步核对控制权按效果期限归还；若出现离场、控制权再次变更或其他干预，只按实际可见结果判断，不预设必然归还。
4. 若效果发动或结算失败、对象不合法或未实际发生控制权转移，标记目标未完成；程序能够重放动作不等同于控制权变化已被验证。

## 录制安排

- 使用人工准备的双方卡组；人工建房、选卡组并完成决斗。
- 使用严格确定性模式：单局 1v1，启用「不洗牌」，起手五张、LP 8000、每回合抽一张、无时间限制。
- 对局结束后审核双端日志、编译报告、无头回放及目标断言，待用户审核后才收录正式回归集。

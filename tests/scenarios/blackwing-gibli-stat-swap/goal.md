# 决斗录制目标：黑羽-热风之基布利②交换原本攻击力与守备力

## 用户原话

> 录制决斗剧本，目标验证 26775203 的2效果，交换攻击力，守备力

## Agent 整理目标

1. 在人工双客户端对局中，于自己主要阶段发动「黑羽-热风之基布利」（26775203）的②效果；记录发动候选、实际选择及双方可见的连锁处理过程。
2. 核对效果成功结算后，这张卡的原本攻击力与原本守备力由 0／1600 交换为 1600／0，并检查双方客户端可见的数值更新与场面状态。若有其他数值修正，区分原本数值与最终显示数值。
3. 若录制覆盖回合结束，进一步核对“直到回合结束时”的期限及数值恢复；若未覆盖，不把恢复标为已验证。
4. 若效果发动或结算失败、卡片离场或出现其他影响数值的效果，按实际可见证据评估目标，不能仅凭动作成功回放认定交换已发生。

## 录制安排

- 使用人工准备的双方卡组；人工建房、选卡组并完成决斗。
- 使用严格确定性模式：单局 1v1，启用「不洗牌」，起手五张、LP 8000、每回合抽一张、无时间限制。
- 对局结束后审核双端日志、场景编译、无头回放和目标断言，待用户审核后才收录正式回归集。

## 双视角证据

1. Host 召唤「剑式阴极雷火沸动机」（35844557）并接受其②效果发动。双端记录 `effect_activated`、`chain_link_added`，该效果是连锁 1。
2. Guest 在普通连锁响应提示选择放弃（录制 Guest #509、#511），之后在连锁 1 处理期间接受「雷火沸动交界机」（06798031）③的 `effect_yes_no`（Guest #518、#520）。随后依次选择「雷火沸动死旋爆震机」及一张超量素材（Guest #525–#534）。
3. Guest 快照显示该超量怪兽素材数从 2 变为 1。双端同一处理区间均收到 `MSG_CHAIN_DISABLED`（Host #495、Guest #542），对应 Agent 服务的 `chain_link_disabled`；随后收到 `chain_link_solved` 和 `chain_ended`。Host 最终卡组仍为 34 张，手牌仍为 5 张，没有执行该怪兽效果的检索。
4. 双端原始消息中，这段从连锁 1 开始至结束的区间只有一次 `MSG_CHAINING`，没有新的连锁项；Guest 接受场地魔法③时的快照 `chain_depth` 仍为 1。由此判定③操作没有另开连锁。YAML 的有序事件断言验证双方“发动 → 连锁处理 → 连锁失效 → 连锁结束”；`event_count_assertions` 在双方各自已接受的事件中要求这段连锁恰有一个 `chain_link_added`，多出一个即失败。

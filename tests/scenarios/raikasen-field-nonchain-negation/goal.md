# 决斗录制目标：雷火沸动交界机③效果

## 用户原话

> 录制决斗剧本，测试 06798031 的3效果，不入连锁无效怪兽效果的发动，你不必查阅卡组文件，我已经都准备好了

## Agent 整理目标

1. 在「雷火沸动交界机」（06798031）表侧存在、自己场上有可取除超量素材的「雷火沸动」超量怪兽时，由对方发动怪兽效果。
2. 在该怪兽效果处理时，确认本方可以选择取除一个对应超量素材，且该操作不另开连锁；记录双方可见的提示、响应和事件顺序。
3. 确认被处理的怪兽效果无效，记录取除素材及后续场面变化。区分“效果发动被无效”与“已发动效果在处理时被无效”，以卡面和实际协议事实为准。
4. 双端日志及录制后的场景回放都应能支撑上述结论；若协议没有直接暴露某项事实，标为未验证，不从最终场面倒推。

## 录制安排

- 使用用户已准备好的双方卡组；录制前不读取或修改卡组文件。
- 本局选择严格确定性模式。房间设为单局 1v1，启用「不洗牌」，起手五张、LP 8000、每回合抽一张、无时间限制。
- 人工完成效果演示并结束决斗后，再检查录制、编译和回放结果。

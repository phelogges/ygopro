# 决斗录制目标：「DNA改造手术」改变表侧怪兽种族

## 用户原话

> 录制决斗剧本，目标验证 74701381 的效果，改变场上所有怪兽的种族

## Agent 整理目标

1. 发动「DNA改造手术」（74701381）时宣言一个种族。卡片文本限定作用于**场上全部表侧表示怪兽**；本次优先让双方场上各有一只原种族与宣言种族不同的表侧怪兽，分别检查变化。
2. 核对发动前双方怪兽的可见 `race`、种族宣言动作、发动后双方怪兽的 `race`，以及陷阱继续表侧存在。双端分别核对本视角快照和 Agent 已接收的 `card_value_changed(field: race)` 事件；事件只报告可见变化，不推断未提供的效果因果。
3. 如果实际对局出现第二次种族宣言、效果无效、陷阱离场或新怪兽进场，按录制事实追加对应的中间状态与事件审核；若没有发生，就标为未验证，不凭卡片文本声称这些分支已覆盖。
4. 若出现里侧怪兽，不要求其显示或改变种族，也不通过另一端日志揭示当前隐藏身份。

## 录制安排

- 人工双客户端建房、选卡组并决斗至终局；实际卡组、怪兽、宣言种族与回合动作以录制事实为准。
- 严格确定性模式：单局 1v1，必须勾选“不洗牌”，起手五张、LP 8000、每回合抽一张、无时间限制。
- 双端原始日志、实际 YDK、编译草稿和单场验证先保留在忽略目录；用户审核后才收入正式测试集。

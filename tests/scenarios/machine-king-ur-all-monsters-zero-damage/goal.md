# 决斗录制目标：「神机王 乌尔」①逐只攻击与②对方战斗伤害归零

## 用户原话

> 录制决斗剧本，验证 96938777 的1效果，向对方全部怪兽各作一次攻击，和2效果，战斗时对方收到的战斗伤害变为0

## Agent 整理目标

1. 在人工双客户端对局中让「神机王 乌尔」（96938777）以攻击表示进入战斗阶段。对手至少有两只可被攻击的怪兽；尽量让这两只怪兽攻击力均低于乌尔当时攻击力 1600、为表侧攻击表示，使通常计算应产生正数战斗伤害，从而有效测试②效果。
2. 使用同一只乌尔向两只不同的对方怪兽分别宣言攻击，按攻击对象格子、双方可见的战斗事件和后置场面核对①效果。若只攻击一只，①目标只能标为部分验证。若攻击对象在战斗中离场或改变，按实际事件判断。
3. 对每次战斗分别核对当时双方战斗数值、伤害步骤、对手实际收到的 LP 伤害事件及前后 LP。若乌尔的攻击力高于表侧攻击怪兽，且未发生其他伤害无效效果，应观察到对手不受到战斗伤害、LP 不变；这才支持②效果成立。不能只用终局 LP 或“没有伤害事件”单独推断。
4. 分别以 Host、Guest 各自可见的事件写断言，记录每次攻击对象及区间内伤害事件的准确次数。①和②在战斗中适用，未必出现单独 `effect_activated`；不要因此判为未发动。

## 录制安排

- 人工准备双方卡组、建房、选卡组并决斗至终局；具体攻击对象和数值按实际录制确定。
- 严格确定性模式：单局 1v1，必须启用「不洗牌」，起手五张、LP 8000、每回合抽一张、无时间限制。
- 双端日志、实际 YDK、编译和单场回放先留在忽略目录；用户审核后才收入正式场景集合。

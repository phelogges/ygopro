# 测试目标：宣言怪兽卡名并结算

## 用户原话

录制决斗剧本，目标验证 39238953 的1效果，输入怪兽卡名，进行效果结算，考察输入卡名这个动作，能否支持未来让agent使用。

## Agent 整理的可核查目标

1. 一方发动「天声的服从」（39238953），支付 2000 LP 后在原生客户端的卡名输入界面宣言一张合法怪兽卡。
2. 双端录制应捕获 `MSG_ANNOUNCE_CARD` 提示、实际输入的卡片密码，以及该密码是否在按 opcode 和当前卡库解析出的允许集合内。Agent 动作应为 `announce_card(card_id)`，不能要求模型生成原始协议字节。
3. 对手卡组含有宣言卡时，继续完成确认、效果分支选择和结算；核对双方各自可见事件及后置区域或 LP 变化。
4. 编译并回放该录制，确认 Agent 决策路径能重现卡名宣言和结算。若在提示解析、允许集合、动作翻译或回放处失败，保留原始日志并定位首个缺口。

## 待录制后确定

- 实际宣言的怪兽卡名与卡片 ID、卡片归属和选用的效果分支，以双端记录为准。
- 若卡组中无宣言卡或录制未完成效果结算，按部分验证记录，不宣称目标通过。

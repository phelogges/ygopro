# 决斗策略知识通用大纲

> 状态：现行写作指南，待用户讨论定稿；面向标准 OCG 两胜制 Match（最多三局），涵盖每局 1v1 决策和局间备牌。项目目前只实现单局 Agent 接管，Match 与换备牌仍属后续实现范围。本文是上层设计，不对应任何具体卡组，也尚未作为运行时指令注入模型。观点来源与适用边界见[理论资料调研](../research/duel-strategy-theory.md)。

## 用途与层次

本大纲规定后续**如何分析并编写**本方卡组、常见对手构筑、泛用手坑与备牌知识。它先提出局内和局间都应考虑的决策问题，再由未来的具体指南填入该构筑自己的胜利方式、资源循环、限制、交互点、备牌计划和实例。卡片文本与规则、当前可见局面和合法动作仍须在实际决斗时核对；策略文档不替代它们。

知识分三层，后层不得把前层的条件判断改写成绝对口诀：

1. **通用决策方法：** 本文的目标、资源、路线、风险和重新评估方法。
2. **专题知识：** 例如阻抗时机、先攻与后攻、局间备牌、隐藏信息、复盘；不绑定某一构筑。
3. **具体构筑知识：** 本方卡组及常见对手构筑的特色、条件式路线和反例，未来再写。

## 一次决策的通用框架

每个动作前只需完成与该动作有关的判断；出现新信息后重算，不把上一动作的计划视为既定剧本。

1. **确定胜利目标与时间压力。** 当前能否直接取胜？如果不能，下一次对手行动是否会造成败局？双方谁更有利于打长局？当前应争取伤害、场面控制还是未来资源？角色可随局面改变。处于 Match 时还要知道当前局数、比分及局间已形成的公开情报；总体目标是提高整场 Match 的获胜机会，每局仍应争取取胜，不能把单局计划等同于整场策略，也不能为卡差或终场强度预设固定权重。
2. **区分事实、推断与未知。** 列出可见资源、已公开历史、效果与召唤限制，以及尚未确认的对手手牌和构筑。只把确定事实用于硬性前提；对未知项保留有依据的备选假设。
3. **提出少数可行路线。** 通常比较高收益路线、保留防护或补点的稳健路线、受干扰后的妥协路线；若后攻，再比较事前降低对手成场质量与事后突破既成场面。没有相应资源时不必虚构路线。
4. **比较投入、结果与失败后果。** 路线要花掉什么不可恢复资源？若关键动作被阻断，还剩什么场面、交互和下一回合起动？最终场面能覆盖哪些威胁，是否被同一种解法一起处理？选择应服务于赢局机会，而非固定追求终场最大或保留最多手牌。
5. **执行并重新评估。** 只提交当前合法动作。对手响应、随机结果、搜索结果和新公开信息可能改变目标或路线。

## 必须覆盖的决策主题

### 胜利路径、资源与对局角色

同时考察可立即使用的牌、可循环但需要条件兑现的资源、场面上的交互能力、生命值与斩杀窗口。卡片数量、攻击力或“几个无效”均不能单独代表优势。若己方长局更强，可考虑以眼前收益换持续资源；若对手长局更强或己方即将败局，应考虑提速。此判断必须依据实际局面，不能由先后攻或卡组标签永久决定。

### 先攻展开的稳定性

写展开策略时，区分**上限、稳健、妥协、停牌后的保留**四类结果。比较路线时至少看：起动所需资源、通常召唤与其他一次性机会、途中产生的防护、关键转换点、结束时的交互覆盖、下回合资源，以及被打断后的残余价值。必要时主动用低代价动作试探阻抗；何时试探、何时先建立保护，应按可承受的失败后果决定。

### 对手回合的阻抗分配

阻抗是否现在使用，要看目标动作在对手路线中的功能、对手已经投入的资源、被阻止后仍可用的补点、自己剩余阻抗的覆盖范围，以及等待更后面时点的风险。多张阻抗需要分工；“能响应”本身不构成发动理由。未知手牌和未知构筑意味着所谓断点只能给出条件和背面风险，不能保证对手停牌。

### 后攻与返场

区分两类计划：在对手先攻时削弱其终场；在己方行动时突破既成场面。突破后还要判断能否斩杀，不能斩杀时能否留下防守和下一回合资源。使用解场手段前，应确认它对本方后续行动施加的限制，以及它是否真正处理对方的后续资源。

### 信息、风险与复盘

公开行动能够缩小对手构筑和手牌的可能范围，却不等于确认未公开卡。比较路线时分别写出“已确认”“较可能”“仅需防范”三种信息状态，并标注判断失效的条件。复盘要使用**决策当时可见的信息**，追溯最早的关键选择；不能拿事后看到的隐藏牌要求 Agent 当时作出确定判断。

## Match 与局间备牌

标准竞技以先取两胜决定 Match。第一局使用初始构筑；后续局可在局间用备牌与主卡组、额外卡组交换。下一局先后攻由上一局败者选择，但换牌时不能把尚未宣布的选择当作事实；即使自己有选择权，也要考虑对手为预期顺序准备的反制。具体交换必须遵守当前比赛规则、禁限表和各卡组张数约束。规则依据与策略资料见[备牌调研](../research/duel-strategy-theory.md#备牌策略调研要点)。

Match 决策应同时考虑当前局面的赢局机会、比分、下一局可能的先后攻与备牌调整。这里不设一套固定的跨局收益分数，也不因整场目标而默认放弃当前局。局间公开信息可用于更新对手构筑和打法的假设；新的一局则有独立的生命值、场面、手牌、墓地及其他局内状态。上一局见过的卡或路线不能证明下一局仍会抽到、保留或使用相同卡片；对手未展示的备牌和新构筑仍属未知。

未来实现 BO3 时，**局间换备牌的方案选择和合法交换均由 Agent 完成**。它需要基于对局公开记录和本方完整构筑选择换入、换出，并在下一局开始前提交可校验的交换结果；具体交互协议、校验边界和失败处理留待 BO3 设计确定。当前单局客户端与 Agent 尚无局间换牌能力，不能把本段视为已实现的操作说明。

### 局间决策循环

1. **复盘刚结束的一局。** 记录当时公开的对手起动、资源循环、胜利方式、场面与解场方式；区分已确认的卡与推测的构筑。明确本方哪些牌在此对局中无效、哪些关键牌或路线暴露了弱点。
2. **判断下一局的先后攻。** 上一局败者有选择权；自己可选时确定最有利方向，对方可选时保留先攻、后攻两种可能，不把对手“通常会选先攻”写成确定事实。无论哪种情况，都要预测对方可能换入的干扰或突破手段。
3. **制定换入与换出方案。** 每张换入牌对应明确任务：保护本方计划、阻止对手成场、突破既成场面，或提高后续对抗能力。先检查有哪些可换出的低效牌及可换出的张数，再选择换入牌；优先剔除在本对局和预计先后攻中作用低的牌。
4. **复核整套构筑。** 主卡组、额外卡组和备牌的交换是否合法；起动、补点、关键检索目标和后续资源是否仍完整；换入牌的使用条件是否与本方路线冲突；若实际先后攻与预期不同，构筑是否仍有可执行计划。没有普适的“必须换入几张”。
5. **进入下一局并更新认识。** Game 2 暴露的新信息可能推翻 Game 1 的假设；Game 3 应重新制定计划，不能机械重复上次交换。对手也可能调整构筑，未公开的备牌身份仍是未知信息。

### 备牌策略的评价维度

| 维度 | 局间要问的问题 |
| --- | --- |
| 针对性 | 换入牌针对的是对手真实的获胜路径，还是仅针对曾见到的一张牌？ |
| 先后攻适用性 | 先攻能否支持建场、防护与对手解场；后攻能否阻止成场或完成突破？若顺序与预期不同会怎样？ |
| 换出成本 | 换掉的牌在本局面是否低效？是否同时削弱起动密度、补点或必要的检索目标？ |
| 协同与冲突 | 换入牌是否要求本方无法满足的条件，或阻碍本方召唤、效果、战斗和返场？ |
| 对手调整 | 对手可能换入什么来针对本方计划？是否把只对 Game 1 构筑有效的答案看得过重？ |
| 可验证性 | 换牌前后能否分别抽到可行动起手；先攻、后攻和吃阻抗后的路线是否仍成立？ |

上述是通用分析框架。未来写具体构筑时，再给出按对局类型及先后攻组织的条件式备牌方案，并写清换入、换出、理由、备选方案和失效条件。标准 Match 的时间与超时裁定可能影响风险选择，但依具体赛事规程变化，不在此大纲内固定某个时间阈值。

## 未来具体指南的覆盖粒度

先按**会改变决策的资源形态和阻抗机制**选代表性分支，不枚举所有五张起手或所有卡片组合。两个起手若共享起动条件、关键瓶颈、可用补点和决策结论，可以归为同一类；若某张牌改变了失败后果或最优路线，就应拆成新类。

每类至少写清以下内容：

| 项目 | 需要说明的内容 |
| --- | --- |
| 前提 | 起动资源、已用效果、区域、限制、先后攻与已知对手信息。 |
| 目标 | 为何选择当前路线；上限、稳定性、返场或斩杀之间取舍什么。 |
| 关键点 | 哪些动作只是在铺垫，哪些是不能失去的资源转换点。 |
| 分支 | 无干扰时的结果；常见且会改变计划的阻抗类型下如何改走。 |
| 残余价值 | 被打断后仍有的场面、手牌、交互与下一回合起动。 |
| 反例 | 什么手牌、公开信息或对手行动会使这条建议失效。 |

阻抗分支按**作用机制**覆盖，例如阻止检索或从卡组调度、无效场上关键效果、移除关键场值、限制后续特殊召唤、处理已成场面；具体构筑写作时再确定哪些机制相关。优先收录常见、损失显著、且应对方式不同的分支。若一个额外分支只重复相同结论，可以合并；若会让“最大场”改成“保留资源”，必须单列。组合阻抗只在其结果无法由单一阻抗分支推得时追加，避免组合爆炸。

这是**写作覆盖原则**，不是声称 Agent 在决斗中只能考虑这些风险。具体指南可依据该卡组的独特资源和当前环境补充新的维度。

## 后续知识文档的责任划分

| 文档 | 从本大纲继承什么 | 未来补充什么 |
| --- | --- | --- |
| 本方卡组指南 | 决策框架、路线分类、资源与失败后果比较。 | 实际构筑的胜利方式、起动与补点、特色限制、代表性分支和返场。 |
| 泛用手坑指南 | 条件式时点、剩余补点与背面风险分析。 | 各类效果的合法窗口、覆盖对象、使用代价和常见反例。 |
| 常见对手构筑指南 | 公开事实与推断分离、对手路线与资源分析。 | 可辨识线索、常见起动、韧性、条件式阻断点和突破方向。 |
| 备牌指南 | 局间决策循环、先后攻分支、换出成本和对手反制。 | 实际备牌池、对局类型下的换入换出、替代方案及复核证据。 |
| 对局复盘 | 当时信息、可控选择、反事实路线。 | 场景或真实对局的证据、失败机制与待修正知识。 |

具体指南须标注适用的 OCG 环境和更新时间、构筑版本、前提、反例与待验证项。验收重点是建议能否帮助选择行动、在新信息出现时改变判断，而不是收集尽可能多的固定连招。至少用以下情形复核：先攻与后攻；关键动作遭阻断后的替代路线；对手局间换牌后原方案的适用性；实际观察推翻原先对构筑或手牌的假设。复核时记录当时可见信息、建议的行动及其理由、合法性和结果；无法用现有运行时验证的项目应保留为待验证，不能写成已通过。

项目当前的单局 Agent 可先验证局内原则；Match 与备牌计划须待相应功能实现后验证，不能因文档覆盖就宣称运行时已支持。经验证后再决定是否把精简原则放进 Agent 通用指令；长篇分析不应每轮无条件送入模型。

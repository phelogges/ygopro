# Agent 可见状态与决策数据流（现行设计）

> 状态：现行设计。适用于当前 Agent 服务的 HTTP v3 路径；字段、端点、错误语义和可见性限制以 [HTTP v3 契约](../contracts/agent-http-v3.md)为准。早期取舍见[历史 v2 状态设计](agent-state-v2.md)。

## 目标与边界

客户端是本方可见决斗事实的来源。服务端持久保存已确认事件和决策时的完整快照，计算前后快照的净差异，并向模型提供本轮新增事实。模型可按需读取完整场面和事件历史。游戏服务端、CTOS/STOC、`ocgcore` 与卡片脚本不因 Agent 接入而改变。

模型的摘要与战术推断属于非权威数据，不能改写客户端快照，也不能让隐藏卡身份进入权威状态。历史隐藏信息依据本方事件记录重建；旧版推断笔记仅保留人类只读归档，见[历史笔记契约](../contracts/agent-knowledge-notes-v1.md)。

## 数据流

```text
游戏消息 → 客户端可见事件与状态 → HTTP v3 → StateDatabase（SQLite）
                                                ├─ 已确认事件、快照、净差异
                                                ├─ 对局上下文与旧版笔记归档
                                                └─ 人类只读视图与轨迹
                       DecisionManager → Pydantic AI 或 Codex
                              │               │
                              │               └─ DuelTools → 状态、历史、技能、客户端查询
                              └─ agent_sdk 动作校验 → 客户端复核 → 原有响应编码
```

客户端在状态与候选一致时冻结一次决策请求。每次真实决策提交完整本方可见快照、有序未确认事件、当前提示和合法候选；没有有效选择的自动询问不进入模型。无决策期间仍可同步事件，终局事件也通过同步路径送达。事件说明发生过什么，快照说明当前可见什么；净差异由确定性程序计算，不代替事件因果。客户端未报告的效果归因、卡片身份和使用次数不得由程序补成事实。

## 持久化与一致性

`StateDatabase` 以本方 `(session_id, duel_id)` 隔离 SQLite 数据。它在确认前校验身份、事件连续性、版本与重传内容，在事务中保存事件、决策快照和差异；确认序号只覆盖已经提交的连续事件。相同请求可幂等重传，不一致的同版本或同事件序号请求被拒绝。数据库保存可查询的历史及轨迹，并提供已确认状态给模型工具和人类只读页面。运行中的模型栈及待处理查询留在内存；服务中断时不把它们伪装成已恢复的决策。具体一致性和失败语义由 HTTP v3 契约规定。

首次接管且没有模型历史时，模型收到已确认的完整可见状态；之后默认收到本轮新事件、快照净差异、提示和全部合法候选。`DuelTools` 从同一已确认镜像提供整体状态、区域、单卡和分页历史，不维护另一套场面事实。模型不暴露重复的客户端查询工具；既有 HTTP v3 查询往返仅供协议兼容和诊断，其返回值必须与本决策冻结快照一致。工具接口及预算见[二期服务设计](agent-phase-2.md#工具与沙盒)。

## 决策与观察

`DecisionManager` 管理当前提示的异步阶段。模型请求客户端只读事实时，服务返回查询阶段，客户端复核并返回结果，再继续模型；最终语义动作经过 `agent_sdk` 与客户端两层校验。客户端还发送动作提交回执，供轨迹区分“服务签发”和“客户端提交”；提交回执本身不证明游戏服务端已经结算。终局到达时取消本局在途决策，拒绝迟到结果。阶段和回执格式见 HTTP v3 契约。

人类页面按配置档、对局和视角读取已确认状态、事件、差异、模型轨迹与旧版笔记归档。事件同步时间和决策快照时间可能不同，页面应分别标示；不能把旧快照说成逐帧实时场面，也不能把历史笔记称为当前 Agent 的判断。显示范围、授权和导出见[可观测性设计](agent-observability.md)与[可观测性契约](../contracts/agent-observability-v1.md)。

## 验证边界

协议夹具与假模型检验事务、可见性、重传、查询和动作安全。双客户端场景回放检验真实 CTOS/STOC 路径；真实模型决策、GUI 人工接管与 Windows 应分别记录，不能由离线测试推定。最新实测入口见[验证总览](../validation/README.md)。
